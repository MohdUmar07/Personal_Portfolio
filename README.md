# Mohd Umar — Modern Developer Portfolio

A responsive, high-performance portfolio website built with **Next.js**, **React**, **TypeScript**, and **Tailwind CSS**. Showcases full-stack software development projects, technical skills in the MERN stack, career experience, and academic milestones.

---

## ⚡ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **UI & Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/) & Custom SVG Brand Icons
- **Contact Service:** [EmailJS](https://www.emailjs.com/)
- **Deployment:** Vercel / Static Hosting

---

## ✨ Features

- 📱 **Fully Responsive:** Optimized for mobile phones, tablets, and ultra-wide desktops.
- 🎨 **Modern Dark Aesthetic:** Glassmorphism, smooth gradients, and subtle glow accents.
- 🚀 **Interactive Navigation:** Smooth in-page scrolling with active section detection and mobile drawer.
- 💼 **Career & Academic Timeline:** Filterable timeline showcasing work experience at SinQlarity and BCA coursework.
- 🛠️ **Categorized Skills:** Visual cards with categorized tech tags (Frontend, Backend, Tools & DevOps, Soft Skills).
- 📂 **Featured Projects:** Interactive project grid with live demo links, source code repositories, and filter tabs (All, MERN, React).
- 📬 **Interactive Contact Form:** Field validation, instant clipboard email copy (`mdumar2506@gmail.com`), and EmailJS delivery.
- 📄 **Resume Download:** Direct one-click download for updated PDF resume.

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/MohdUmar07/Personal_Portfolio.git
cd Personal_Portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for production
```bash
npm run build
npm start
```
